## 🧠 **Core Vision**

Quantalink fuses **Quantum Physics** + **Next.js Web Engineering** into a
**visually immersive, and technically elegant** portfolio.

---

## ✨ **Key Features**

### 🎨 **Design & Aesthetics**

- **Glassmorphism UI** with `backdrop-blur` + layered transparency.
- **Quantum-Inspired Animated Background** simulating vacuum fluctuations & quantum foam. _[learn more](./APPENDIX.md#Background)_
- **Framer Motion** for cinematic transitions, 3D tilt cards, and parallax effects.

---

### 🗂 **Multi-Page Architecture**

| Route       | Purpose                                            |
| ----------- | -------------------------------------------------- |
| `/`         | Landing page with **overview + CTAs**              |
| `/about`    | Personal & professional journey                    |
| `/skills`   | **InfiniteScroller** ribbons + official tech logos |
| `/projects` | Dynamic portfolio grid + hover-glow interactions   |

---

### 🕹 **Easter Egg — Quantum Conundrum**

- Schrödinger’s Cat–themed **mini-game** with levels, timers & outcomes.
- **Page Pets**: Win → Alive Cat 🐱 | Lose → Quantum Ghost 👻
- Particle engine with **capped FPS & render limits** for smooth performance. _[learn more](./APPENDIX.md#-the-quantum-conundrum-mini-game)_

## 📈 **SEO + Performance**

- **Page Metadata** → Distinct titles, descriptions, canonicals, and social previews for each page, using the name `Akshay Abraham`.
- **Structured Data** → Person JSON-LD identifies Akshay and links his public profiles.
- **Image SEO** → Descriptive photo filenames and alt text, with image URLs in the generated sitemap.
- **Sitemap** → `sitemap.xml` and `robots.txt` are generated by `next-sitemap` after the build.
- **Agent-readable summary** → `/llms.txt` links to the same public facts on the website. It is supplementary and does not control indexing.

After deploying, submit `https://akshayabraham.vercel.app/sitemap.xml` in Google Search Console and use URL Inspection on the homepage and `/about` to request a crawl. Search appearance depends on Google's indexing and is not guaranteed by metadata alone.
